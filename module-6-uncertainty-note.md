# Module 6: Uncertainty note and self-check

Part of the Veritale skill. Read `SKILL.md` first. Always run this module last.

## Purpose

Tell the reader plainly what is not certain, then check the whole answer before sending it.

## Part A: the uncertainty note

Write a short section headed "What we are unsure about".

1. List every Disputed and Legend claim that appears in the timeline or the story.
2. Give each one a single line: what the claim is, and why it is uncertain.
3. Put the most important doubt first, usually the one that changes how the event is understood.
4. If a well-known story was left out because the evidence is too weak, say so in one line.
5. End with the label key: Verified = broad agreement; Disputed = sources disagree; Legend = late or traditional source only.

Example line:

```
- The arrow in Harold's eye: the Bayeux Tapestry figure is unclear and was restored in the nineteenth century, and early written sources describe his death differently.
```

## Part B: the self-check

Go through this list before replying. If any answer is "no", fix the output first.

- [ ] Does every claim in the story appear in the fact table?
- [ ] Does every timeline line carry a label?
- [ ] Is every Disputed and Legend claim framed or labelled in the story?
- [ ] Is there no invented dialogue, name, number or motive?
- [ ] Are approximate dates marked with "c."?
- [ ] Where sources disagree, are both sides named?
- [ ] Are claims about what a source says kept separate from claims about what happened?
- [ ] Does the uncertainty note list every Disputed and Legend item?
- [ ] Does the length match the brief from module 1?
- [ ] Does the label key appear at the end?

## Output of this module

The "What we are unsure about" section and the label key, added to the end of the answer. The checklist itself is not printed unless the user asks to see it.
