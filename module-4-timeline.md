# Module 4: Timeline

Part of the Veritale skill. Read `SKILL.md` first. Skip this module in `story` mode.

## Purpose

Turn the graded fact table into a clean chronological list that a reader can scan in under a minute.

## Line format

```
[date] | [event in plain words] | [Label] | [short source note]
```

Example:

```
c. 261 BCE | Ashoka's army conquers Kalinga, in the eighth year after his consecration | Verified | Major Rock Edict XIII
```

## Date forms

| Case | Write it as |
|---|---|
| Exact day known | 1066, 14 October |
| Year known | 1757 |
| Approximate year | c. 261 BCE |
| Range | c. 273 to 268 BCE |
| Only "before" or "after" known | before 1200 CE; after 1526 |
| Regnal year converted to a modern date | c. 261 BCE (eighth regnal year) |
| Dates in two calendars | Give the common-era date first, then the other calendar in brackets |

## Sorting rules

1. Sort by the earliest possible date.
2. BCE dates count down: 273 BCE comes before 268 BCE.
3. When two events share a date, put the cause before the result.
4. An undated Legend item goes next to the event it is attached to, with "undated" in the date column.
5. Put events in the order they happened, not the order in which the sources were written. If the date of a source matters (for example, a story first written down 300 years later), give it in the source note.

## Rules

- Every line keeps its label. Never drop the label to make the list look tidy.
- Keep each event to one line of plain words. Save detail for the story.
- Use the same date form all the way down the list.
- Do not add events that are not in the fact table.

## Output of this module

The finished timeline, ready to print under the heading "Timeline".
