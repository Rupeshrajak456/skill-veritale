# Module 3: Evidence grading

Part of the Veritale skill. Read `SKILL.md` first.

## Purpose

Give every row in the fact table one label: **Verified**, **Disputed** or **Legend**. This is the heart of the skill.

## Decision steps

Work through the steps in order and stop at the first one that fits.

1. **Is the earliest source far removed from the event?** If the claim first appears two or more generations later, or only in tradition, hagiography or court praise, and no early source supports it, label it **Legend**.
2. **Do credible sources or historians disagree?** If they disagree about whether it happened, when it happened, who was involved, how it happened or how large it was, label it **Disputed**.
3. **Does the claim rest on early evidence and broad agreement?** If it appears in primary or near-contemporary sources, and standard scholarly accounts state it without serious challenge, label it **Verified**.
4. **Still unsure?** Choose the weaker label. Prefer Disputed over Verified, and Legend over Disputed. Write one line in the Notes column explaining why.

## Label formats

Use these forms in the timeline. Keep the reason short.

```
[Verified]
[Disputed: Source A says X; Source B says Y]
[Legend: first told in Source C, written about N years later]
```

## Special cases

| Situation | What to do |
|---|---|
| A single source gives a number (deaths, army size) | The claim "Source X states N" can be Verified. The number as a real count is usually Disputed. |
| A ruler's own inscription describes his feelings or motives | "The inscription says he felt remorse" is Verified. Whether the feeling was sincere is a matter of interpretation; say so. |
| The event is certain but the exact date is not | Grade the event as Verified and mark the date with "c.". If historians argue for clearly different dates, grade the date as Disputed. |
| Legend that is famous and culturally important | Keep it if it helps the reader, but label it Legend and say where it comes from. Do not quietly drop it or quietly accept it. |
| Modern historians agree a popular story is false | Label it Legend and state that historians reject it. |
| You cannot name any source | Grade no higher than Disputed and add "source uncertain". |

## Rules

- Grade claims, not whole events. A Verified battle can contain Disputed details and Legend anecdotes.
- Do not upgrade a label because a story is popular, dramatic or often repeated.
- Do not downgrade a well-attested claim just because a fringe writer rejects it. Disagreement must come from credible sources or historians.
- Count your labels. If every claim is Verified, check again; most real topics contain at least one Disputed point.

## Output of this module

The fact table with one extra column, **Label**, filled for every row.
